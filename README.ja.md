# 3Dモデル自動パーツ分割

[简体中文（デフォルト）](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

**色分けされた一体モデルを、色ごとにプリントして組み立てられるパーツへ。**

気に入った猫のモデルを見つけて、目や鼻、耳を別々にプリントしたい。ところがファイルを開くと、色は分かれていても、パーツは一体のまま。自分で分割するには、モデリングや切断、取り付け穴の作成から覚える必要があります。

このツールは、その手間を減らすためのものです。対応するペイント済み3MFをAIアシスタントに渡すと、分割に適した色領域をパーツに分け、対応する取り付け部を作成します。元の配色と組み立て位置を保った3MFを受け取り、スライサーで確認してプリントの準備を進められます。

モデリングに詳しくなくても、多色の作品を作りたい3Dプリント愛好家向けです。小さな猫をプリントするために、まずモデリング講座へ通う必要はありません。

## こんなときに役立ちます

| 困っていること | できること |
| --- | --- |
| 色は付いているのに、目や口、装飾を個別に選んでプリントできない | 分割に適した色領域を独立パーツにして、色やプリント方法を別々に決められます |
| 別々にプリントして組み立てたいけれど、取り付け部を作れない | 対応する差し込み部と受け穴を作り、組み立て用の余裕を設けます |
| 分割後に配色が変わったり、取り付け位置が分からなくなったりしそう | 元の配色、AMSフィラメントスロット、組み立て位置を1つのモデルに保持します |
| 小さな模様を別パーツにするか、文章だけでは判断できない | 確認が必要な領域を全体図と拡大図で示し、独立パーツとして残すか選べます |

## 分割するとどうなる？

同じ猫の頭を分割した例です。一体のペイント済みモデルから、耳、額の模様、目、鼻、頬などを個別パーツとして組み立てる形にできます。

| 分割前：色は付いていても一体 | 分割後：別々にプリントして組み立て |

## 自分のモデルでも使える？

現在は、読み取り可能なペイント情報を含む **Bambuのペイント済みプロジェクト3MF** を重点的にサポートしています。拡張子が `.3mf` であることや、見た目に色が付いていることだけでは、対応を判断できません。まずAIアシスタントにファイルを確認してもらえます。

単色モデルの自動分割にはまだ対応していません。極端に薄い部分、破損したモデル、複雑なパーツ構成では、修復や分割方法についての確認が必要になる場合があります。

## はじめ方

AIアシスタント向けのSkill（スキル）です。Skillのインストール、モデルファイルへのアクセス、Pythonの実行に対応したAIアシスタント環境で使用してください。

### 1. AIにインストールを依頼する

次の文章をコピーして送ってください。

```text
https://github.com/BensonZeng00/automated-3d-model-splitting から automated-3d-model-splitting 2.1.0 Skill と必要な依存関係をインストールしてください。完了したら、付属の猫の頭のサンプル cathead.3mf で試すか確認してください。
```

サンプルで流れを試しても、自分のモデルから始めても構いません。

### 2. モデルを渡して、希望を伝える

ペイント済み3MFをアップロードするか、ファイルの場所を伝えて依頼します。

```text
$automated-3d-model-splitting を使って、このモデルを色ごとにプリントして組み立てられるパーツに分割してください。元の配色を保ち、アセンブリ3MFを出力して、検証結果を説明してください。
```

大切なディテールがあれば、「目、口、舌を残し、ほかのパーツで隠れないようにしてください」のように追加できます。判断が必要な小領域はAIが画像で示し、あなたの選択に沿って続けます。

### 3. 結果を開いてプリントを準備する

処理と検証が完了すると、**アセンブリ `.3mf` ファイル**を受け取れます。元の配色と組み立て位置を保ちながら、各パーツを個別に選択できます。スライサーで開き、ディテールを確認して各パーツのプリント方法を決めてください。

AIはパーツ数、配色の保持、検証の合否、確認が必要な点も説明します。処理が完了しなかった場合は、停止した箇所と完了済みの作業を伝えます。

## プリント前に知っておきたいこと

**はめ合いは試し刷りで確認してください。** 現行バージョンでは、組み立て用の余裕を設けるため、本体以外のパーツ全体を既定で原寸の99%に縮小します。本体の寸法は維持します。外形寸法や接合部の隙間も変わるため、モデル、材料、プリント設定に合わせて確認が必要です。

**ファイルの検証だけで、実物の組み立てまでは保証できません。** AIはモデル、配色、組み立て構成を検証し、許容差の範囲で合格した項目も説明します。プリント前に、スライサーで全体、パーツ一覧、目や口などのディテールを確認してください。判断に迷ったら、スクリーンショットをAIに共有できます。

複雑なモデルでは、処理の進捗と問題の記録を残すよう依頼すると、後から作業を続けやすくなります。
