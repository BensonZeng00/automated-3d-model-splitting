# 安装确认与替换边界

安装入口为 `tools/install_skill.py`，可复用安装逻辑位于 `tools/skill_install.py`。安装流程只负责部署技能与依赖，不运行模型。使用说明与可接受的回答见 [安装说明](../tools/INSTALL.md)。

- 一句话安装依赖仓库可发现的执行约定：README 提供简短请求，根目录 `AGENTS.md` 和 Skill 安装段引导助手读取安装说明并调用同一 CLI。环境选择与参数组装属于助手职责；知情确认属于用户决定。不要要求用户在每次请求中重复内部脚本路径和规则。此约定已写入文档，但跨助手的实际执行效果需要各自环境验证。

- 修正先前的双项确认规则：统一显示提示后只收集明确同意，不再询问套餐情况，删除旧套餐参数。CLI 和核心入口均校验同意；参数只能承载本次会话实际取得的同意。运行时提示由 `USAGE_NOTICE` 定义，安装前与成功后复用，成功后不再次等待确认。

> 拆件可能消耗较多 token，复杂模型有可能失败；如果没有 Coding Plan，请谨慎使用，并对 token 消耗做好预期。明确确认后才安装

- 确认必须早于复制和任何子进程调用。缺少交互输入时应明确退出，不应默认同意；测试使用临时目录与模拟子进程，不调用真实 pip 或写入用户技能目录。
- 修正先前的备份恢复策略：旧版与新版按不兼容版本处理。在临时目录完成依赖和入口验证后，完整删除目标旧技能，再安装新版；不备份、不恢复旧版，也不把新版覆盖进含旧文件的目录。递归删除前重新核对解析后的目标路径及技能目录标记。
- 删除旧版失败时立即停止；删除后新版写入失败需重新安装。验证失败且尚未删除时，旧技能文件仍在，但不能据此保证可运行：pip 对共享 Python 环境的改动无法自动撤销。
- 安装复制复用发布工具的生成目录排除规则，并保留许可、参考资料和可选工具。新增发布排除规则时同时评估安装载荷影响。
- 安装器返回并操作解析后的绝对路径，测试也应在夹具入口统一对临时根目录调用 `resolve()`。系统临时目录可能含父目录链接或路径别名；仅按未经解析的路径比较，会同时导致结果断言失败和删除故障模拟未命中。不要为此取消生产代码的路径解析或安全检查。

上述确认顺序、删除前失败的原目录保持、旧文件清理及删除和写入失败行为由 `tools/tests/test_skill_install.py` 的隔离测试验证；真实依赖解析仍取决于用户环境和包源。

- 官方助手安装统一调用安装器；禁止以手动复制或单独 pip 绕过确认。README、安装说明、AGENTS 与 Skill 使用上述同一原句，不另写不同的风险提示。
