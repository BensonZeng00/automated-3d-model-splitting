# 涂色 3MF 拆件开发指南

本指南面向从涂色区域识别、冻结共享边界、规划接口到导出装配 3MF 的开发工作。优化目标是稳定得到可由用户调整的拆件结果，并把不确定性准确定位到零件或接口。不要为了消除无关紧要的亚毫米差异，增加全模型的高成本搜索、过密校验或按模型编号编写的特殊规则。

## 一、保持阶段之间的契约

| 阶段 | 应产出的事实 | 后续阶段不得做的事 |
| --- | --- | --- |
| 区域识别 | 源面归属、零件候选、接触双方 | 靠接口生成结果反向改写无关源面 |
| 边界冻结 | 双方共用的一条几何曲线及其来源映射 | 再从各自原始边界独立生成接缝 |
| 接口规划 | 榫卯身份、轴线、方向证据与置信度 | 把零件身份或表面接近度直接当作材料内向 |
| 几何生成 | 接口面、局部外壳过渡和可追溯的调整记录 | 改动已冻结的共享边界以掩盖过渡问题 |
| 导出回读 | 零件、颜色、装配结构和网格审计 | 把文件写出成功等同于打印配合成功 |

几何坐标在构造链中保留原精度；只对报告和界面显示舍入。修改上游边界、归属或方向算法后，重建所有依赖工件并更新指纹。用户对旧指纹的确认不能自动证明新几何已经获确认。

## 二、用证据决定材料方向

接口的榫卯身份、轴线和轴线正负号是三个不同问题。先确定接触双方及共享边界，再估计无符号轴，最后确定哪一侧进入卯方材料。推荐按以下顺序使用证据：

1. 具有来源映射的边界半边和局部材料拓扑；
2. 一致、可信的源表面法向；
3. 沿两个候选方向的局部进入/退出事件；
4. 表面距离和零件中心投影等弱线索。

弱线索不能覆盖明确相反的强证据。凹陷、环状或包裹形表面尤其不能用“最近的卯方三角形”或“指向卯方中心”代替材料侧判断。强证据矛盾时报告接口歧义；只有弱证据可用时可以尝试低置信度方向，但须在结果中提示用户核对。

## 三、让厚度探测表达准确的语义

一次射线查询至少区分三件事：查询起点是否在材料内、它穿过哪些进入/退出事件、查询最大距离是否覆盖目标区间。首次向外命中是**局部首次退出**，不是天然的宿主背壁或完整厚度；无命中只表示给定距离内未发现退出，也不是无限厚度。

厚度或穿出报警应按顺序排查：

1. 核对起点、方向、最大距离及是否从空气中出发。
2. 查看有序进入/退出事件，识别与目标宿主相连的材料区间；不能无条件取最远出口，因为它可能属于无关壳体。
3. 对短凹槽或短空气间隙，允许在明确容差内继续探测，并记录被跨过的间隙。默认可把约 1 mm 作为局部近似的上限，不能据此忽略明显的外露或穿透。
4. 将“候选结构是否碰到可见外壳”“卯底到背壁是否有余量”分别报告；二者不应共用一个笼统的“厚度不足”原因。

保持 API 语义单一：需要首次退出的调用保留首次退出查询；需要跨短间隙或分析材料区间的调用使用另一个明确命名的查询。若为了性能只查询有限射线长度，诊断也应明确这是有限路径检查，不能声称测得整体厚度。

## 四、在冻结前消除边界缺陷

“顶点 ID 不重复的闭环”只是图拓扑条件，不保证三维曲线无零长边、共线回折、T 接点或自接触。边界简化和平滑属于形状处理，不是几何有效性证明；一旦回退原曲线，也必须重新检查回退结果。

推荐流程是：提取来源映射 → 清理明确的短无面积往返段 → 简化和平滑 → 检查闭合、三维回折/自交和形状偏差 → 冻结。只允许在共享接口边界及其局部外壳过渡范围内修改几何。长回折、真实分叉和多环歧义不应被“只保留最大环”静默抹掉；无法可靠决定时保留诊断并让该接口单独失败。

## 五、局部容差与过渡面

约 1 mm 是处理局部源几何噪声的工程容忍度，不是所有尺寸的统一精度，也不能覆盖用户设定的装配间隙。每个容差须写明对象、目的和最大实际偏移：例如短空气间隙、短共线回折、源外壳切口的局部位移。优先采用简单、固定上限且可记录的局部处理；没有证据表明其必要时，不增加全模型迭代优化。

共享边界必须保持固定。如果源外壳切口与接口边重合，形成零面积连接三角面，可轻微移动允许修改的源切口边，保留冻结接口边。生成面仍需检查零面积、边连接、朝向和开口；不能通过跳过退化面检查换取导出成功。所有近似应输出接口 ID、影响点数和最大移动量，便于用户定位后手工修整。

源网格已有的退化三角面需要与新生成的退化面分开判断。裁切后仍可追溯到同一源退化面的候选，按三个顶点的一一对应关系检查最大空间位移，并限定为 1 mm；同一源面不能衍生出多个退化面。记录保留数量和最大位移。新生成的退化面继续阻断，边界匹配的最大偏差也限制在 1 mm。面积退化阈值以 mm² 计，不能与空间位移阈值混用。完整零件和导出回读仍需分别通过检查。

## 六、错误分级与验收

- **阻断接口生成：** 关系或方向无法可靠确定、共享边界无效、生成了开口或零面积面、必要结构明显穿出、装配间隙或 3MF 回读失败。报告具体接口与失败证据。
- **可继续并提示用户：** 源模型的无关缺陷、容差内的局部短间隙或微小切口调整、低置信度但有明确回退依据的方向。记录位置和实际数值，不称为“完全无问题”。
- **必须由实物或人工视图确认：** 可见表面过渡、打印后配合和装配手感。闭合性、颜色和包结构通过，只证明对应技术检查通过。

开发验证先用少量通用合成案例覆盖方向反转、短/长间隙、短/长回折与边界重合，再对实际输入运行全部接口和零件，导出后重新读取 3MF。针对失败补测试；不为可逆的小调整堆叠重复检查。性能评估至少记录接口数量、生成耗时和异常接口，防止局部修复让常规模型拆解显著变慢。

经用户确认的复杂模型可作为黄金回归用例：从原始输入重新跑完整阶段，先比对零件成员与接口关系，再允许测试临时通过确认门槛；最后把导出结果与已确认产物按颜色、闭合性和带容差的几何指标比较。不要以文件哈希或三角面数完全一致作为成功条件，也不要让测试自动更新黄金产物。大型回归可设为手动触发，常规提交继续使用快速单元测试。

黄金用例若包含用户改过的榫卯角色，应把修正规则和最终零件配对分别记录并检查。接口编号可能随规划顺序变化；比较几何关系时以接触零件对为键，再将经审核的编号映射写入临时阶段计划。确认指纹须按最终计划重算，避免测试绕过阶段 04 的审核契约。最终产物还要核对榫卯角色索引，防止只交换编号而没有交换实际角色。
