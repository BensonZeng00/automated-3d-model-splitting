# 3Dモデル自動パーツ分割

[简体中文（デフォルト）](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

3Dプリントは好きだけれど、モデリングは難しい——そんな方でもモデルをパーツ分割できます。

見た目は色分けされていても、実際には一体メッシュの3Dモデルが数多くあります。目、口、服、装飾などを別々に印刷するには、通常はモデリングソフトで切断、面の修復、穴加工、クリアランス調整を行わなければなりません。

このツールは一般ユーザーやホビーユーザー向けのAI 3Dモデル分割Skillです。色付き／ペイント済み3MFを渡すと、印刷可能な色領域を認識し、差し込み部と受け穴を作成して、スライス可能な検証済みアセンブリ3MFを出力します。単色モデルにはまだ対応していません。

BlenderやCADの知識は不要です。複雑なパラメーターとの長い面談もありません。

## 主な機能

- 表面の色から独立した印刷パーツを自動認識
- 幾何学的・構造的根拠に基づく本体の選択
- 各パーツの内向き差し込み形状と対応する受け穴の生成
- 元の色とAMSフィラメントスロットの保持
- 全パーツを1つのグループ化アセンブリとして出力
- 入れ子パーツの再帰処理と各工程の検証
- 親パーツの肉厚に応じた差し込み深さとクリアランスの調整
- トポロジー、面の向き、色、材料スロット、アセンブリ、可視ディテールの最終検証

## インストール

AIアシスタントに次の文章を送ってください。

```text
https://github.com/BensonZeng00/automated-3d-model-splitting から automated-3d-model-splitting Skill をインストールし、必要な依存関係のインストールとプリフライトを実行してください。完了後、cathead サンプルでテストするか確認し、同意した場合は自動でパーツ分割して結果を報告してください。
```

インストールとプリフライトが成功すると、アシスタントが `cathead` サンプルを使うか確認します。同意すると、検証済みのサンプルを取得し、パーツ認識、アセンブリ3MFの生成、最終検証まで自動実行します。同意しない場合、サンプルのダウンロードも読み込みも行いません。

## 使い方

ペイント済み3MFをアップロードして、次のように依頼します。

```text
$automated-3d-model-splitting を使ってこのモデルを分割し、グループ化アセンブリと最終検証結果を出力してください。
```

重要なディテールも指定できます。

```text
このモデルを分割してください。口、舌、目を隠さず、検証結果を残してください。
```

## 出力

本体、目、口、装飾などが元の位置と色を保ったまま、個別に選択・印刷できる1つのアセンブリ `.3mf` が出力されます。

パーツ数、保持された色、アセンブリ構造、検証結果も報告されます。スライサーでの確認が必要な場合は、最終ファイルを開き、モデル全体、展開したアセンブリツリー、重要箇所のスクリーンショットを提供してください。Skillがスライサーを操作することはありません。

## 対象モデル

現在は三角形ごとの表面ペイント情報を持つ3MFを対象としています。ファイル破損、構造上の曖昧さ、識別できない複数インスタンスがある場合は、推測で出力せず理由を説明して停止します。
