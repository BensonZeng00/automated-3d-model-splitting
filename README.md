# 自动化3d模型拆件

[简体中文（默认）](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

喜欢 3D 打印，但不会建模，也能自己拆件。

很多模型看起来已经涂好了颜色，实际上仍是一整个模型。想把眼睛、嘴巴、衣服或装饰件分开打印，往往要重新学习建模软件，自己切割、补面、挖孔，还要反复调整装配间隙。

这是一个为普通玩家和业余爱好者准备的 AI 3D 模型拆件工具。你只需要把彩色 3MF 或涂色 3MF 交给大模型，它会自动识别哪些地方应该成为独立零件，做好对应安装位，最后给你一个可以继续切片打印的装配版 3MF。
（单色版本暂不支持，还在研发中）

不需要会 Blender，不需要会 CAD，也不需要理解复杂参数。

## 它能帮你做什么

- 按模型表面的颜色自动拆出独立零件；
- 根据几何与结构证据判断主体，并为其他零件做好向内插入结构和安装孔位；
- 保留原来的颜色和 AMS 材料槽；
- 把所有零件放在同一个装配模型里，不会拆成一堆散件；
- 递归处理嵌套零件，并校验每一层输入与装配状态；
- 根据父体厚度限制插入深度，自适应调整装配间隙；
- 交付前自动检查模型拓扑、绕序、颜色、材料槽与装配是否完整；
- 重点检查眼睛、嘴巴、舌头等小细节有没有被错误遮挡。

## 安装

把下面这句话发给大模型：

```text
请从 https://github.com/BensonZeng00/automated-3d-model-splitting 安装 automated-3d-model-splitting Skill，安装所需依赖并完成预检；完成后询问我是否使用 cathead 示例模型测试，如果我同意就自动拆件并告诉我结果。
```

安装和预检成功后，大模型会询问是否用仓库自带的 `cathead` 模型做第一次测试。选择同意，它会自动取得示例模型、先识别零件，再生成并验证装配版 3MF；选择不同意则不会下载或读取示例。

## 使用

上传涂色 3MF，然后说：

```text
使用 $automated-3d-model-splitting 拆分这个模型，输出装配版本并保留最终验证结果。
```

如果有特别在意的地方，也可以直接告诉它：

```text
帮我拆分这个模型。嘴巴、舌头和眼睛不能被遮挡，完成后保留测试结果。
```

## 最后会得到什么

你会得到一个装配版 `.3mf` 文件：主体、眼睛、嘴巴、装饰件等都已经成为可以单独选择和打印的零件，同时仍保持原来的位置和颜色关系。

大模型还会告诉你拆出了多少个零件、颜色是否保留、装配和模型检查是否通过。

如果需要在切片软件里进一步确认，请你打开最终文件并把整体模型、装配列表和重点细节截图发给大模型。它不会代替你控制切片软件。

## 目前适合哪些模型

目前主要用于带表面涂色信息的 3MF。模型结构太复杂、存在多个无法区分的实例，或者文件本身损坏时，大模型会先说明问题并请你确认，不会随便生成一个看似完成但无法使用的结果。
