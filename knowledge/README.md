# 开发知识库

本目录积累可复用的拆件开发知识：几何约束、故障识别、排查顺序和取舍原则。每次拉取或合入远端代码，以及推送含新经验的本地代码前，按根目录 [AGENTS.md](../AGENTS.md) 检查并更新相关条目。

条目应回答“开发者下次该如何设计、判断和处理”，写清适用条件、阶段契约、推荐排查顺序、可接受的近似及其风险。具体模型的故障日志、提交范围和单次测试结果留在任务或提交记录中，不写入通用指南。没有证据的推测要明确标注；发现旧建议有误时直接注明修正。

## 条目

- [准入、失败退出与低输出日志](strict-execution.md)：子模型选择、分阶段预算、严格失败行为、摘要与 JSONL 分级读取。

- [涂色 3MF 拆件开发指南](splitting-development-guide.md)：阶段契约与确认续跑、材料方向、射线语义、边界有效性、共享接触环与宿主选择、曲面判定与开槽范围、局部容差、黄金回归偏差排查、独立安装与发布验证及验收。
