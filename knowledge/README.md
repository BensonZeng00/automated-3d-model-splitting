# 开发知识库

本目录积累可复用的拆件开发知识：几何约束、故障识别、排查顺序和取舍原则。每次拉取或合入远端代码，以及推送含新经验的本地代码前，按根目录 [AGENTS.md](../AGENTS.md) 检查并更新相关条目。

条目应回答“下次遇到类似模型时如何判断和处理”，写清适用条件、不得破坏的约束、推荐排查顺序、可接受的近似及其风险。提交、案例和测试结果只作为简短证据。没有证据的推测要明确标注；发现旧建议有误时直接注明修正。
