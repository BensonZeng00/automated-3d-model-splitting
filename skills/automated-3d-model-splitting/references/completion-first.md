# Completion-first exception handling

优先完成可用拆件。异常大小决定处理路径，不单独决定能否继续。

## 两级处理

- **严格小于 1%**：优先采用一次成批的局部舍弃、相邻归并、边界简化，再平滑共享分界。保留整体表面、颜色、关键部件和有效连通性；无需逐项确认。
- **达到或超过 1%**：按外形、部件身份、连通性及装配影响评估，而非比例一票否决。能用局部合并或有限修复完成就继续。若某种策略失败，优先局部重放并更换有依据的策略；复用已完成阶段，不重复整机试跑。
- **没有合适比例的异常**：直接按影响判断，不虚构百分比。

上述原则适用于边界、背衬、局部厚度、三角化、拓扑、布尔运算、装配和文件检查。对运行时或依赖问题直接修复软件；不要把它们计作模型失败。仅在主要外形明显受损、必须保留的部件会丢失、主要装配关系被破坏，或经有限修复仍无法生成有效实体时暂停。无法生成的实体不能靠关闭检查变成成品；可打开但需观察调整的装配应如实交付，标注实际问题。

## 量化与预算

边界使用累计受影响面积／本阶段各受影响部件修复前的表面积，严格 `< 0.01`；恰好 1% 进入影响评估。冻结分母，累计受影响三角面集合，避免每次迭代重置预算。用面积而非面数，避免加密网格改变判定。不得用大主体面积稀释小部件损失。

装配干涉继续使用交集体积／原始实际切削体积。其他问题使用与其物理含义匹配的指标，不混用平方毫米、立方毫米、长度和面数。百分比不能代替主要外观、身份和装配影响判断。

## 代码与人工判断的分工

`boundary_simplification.py` 对小投影交叉区采用有界局部归属转移，只有累计面积、连通性和分界拓扑复核通过才提交；不能只删除面的数据而在表面留下洞。`boundary_review.py` 优先采用同样通过检查的小范围分叉归并。

对于达到 1% 的分叉候选，程序按可验证的影响继续判断：所有原部件保留、不增加断开的区域、仅改变固定局部带内的归属、顶点/三角面/颜色不变、分界恢复清晰时，选受影响面积最小的候选继续平滑，并记录 `completion_priority_local_merge`。后续重新生成母槽和子件，保留实体及装配检查。

更复杂的投影交叉或实体异常可能仍需要代理选择修复方法。工具返回诊断或待审核候选并不等于必须向用户提问；先按总原则判断并完成可行修复。已有用户授权可覆盖同类后续问题。无法自动判定主要外形或关键部件影响时，说明具体取舍再询问，不能只说“超过 1%”。

## 平滑与结果记录

`smooth` 是唯一边界模式。局部归属清理后，使用现有样条和共享表面带算法生成平滑分界，两侧共用边界。记录受影响部件、面积/体积及分母、累计比例、采取的动作、保留的外形和部件、验证结果。输出无需堆砌每个微小告警，只报告影响用户使用的剩余问题。
