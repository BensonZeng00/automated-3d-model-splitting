# 자동 3D 모델 파트 분할

[简体中文（기본）](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

**색칠된 일체형 모델을 색상별로 출력하고 조립할 수 있는 파트로 나눕니다.**

마음에 드는 고양이 모델을 찾아 눈, 코, 귀를 따로 출력하고 싶은데, 파일을 열어 보니 색상만 나뉘어 있고 모델은 한 덩어리입니다. 직접 나누려면 모델링부터 자르기, 조립용 홈 만들기까지 배워야 합니다.

이 도구는 그 과정을 도와줍니다. 지원되는 페인팅 3MF를 AI 어시스턴트에게 전달하면 분할하기 적합한 색상 영역을 파트로 나누고 서로 맞는 조립 구조를 만듭니다. 원래 배색과 조립 위치를 유지한 3MF를 받아 슬라이서에서 확인하고 출력을 준비할 수 있습니다.

모델링에 익숙하지 않아도 여러 색의 작품을 만들고 싶은 3D 프린팅 취미 사용자를 위한 도구입니다. 작은 고양이 하나 출력하려고 모델링 강좌부터 등록할 필요는 없으니까요.

## 이런 상황에 도움이 됩니다

| 겪고 있는 문제 | 도구가 돕는 방법 |
| --- | --- |
| 색은 칠해져 있지만 눈, 입, 장식을 따로 선택해서 출력할 수 없음 | 분할에 적합한 색상 영역을 독립 파트로 만들어 색상과 출력 방법을 각각 정할 수 있습니다 |
| 따로 출력해서 조립하고 싶지만 결합부를 만들 줄 모름 | 서로 맞는 삽입부와 홈을 만들고 조립 여유를 둡니다 |
| 분할 후 색상이 바뀌거나 파트 위치를 잃어버릴까 걱정됨 | 원래 배색, AMS 필라멘트 슬롯, 조립 위치를 하나의 모델에 유지합니다 |
| 작은 무늬를 별도 파트로 출력할지 설명만으로 판단하기 어려움 | 확인이 필요한 영역의 전체 모델 이미지와 확대 이미지를 보여 주어 독립 파트로 남길지 선택할 수 있습니다 |

## 내 모델도 사용할 수 있나요?

현재는 도구가 읽을 수 있는 페인팅 정보를 포함한 **Bambu 페인팅 프로젝트 3MF**를 중점 지원합니다. 확장자가 `.3mf`이거나 화면에서 색상이 보인다는 이유만으로 호환되지는 않습니다. 먼저 AI 어시스턴트에게 파일을 확인해 달라고 요청할 수 있습니다.

단색 모델의 자동 분할은 아직 지원하지 않습니다. 매우 얇은 부분, 손상된 모델, 복잡한 파트 관계는 수정하거나 분할 방법을 직접 판단해야 할 수 있습니다.

## 시작하기

AI 어시스턴트용 Skill(스킬)입니다. Skill 설치, 모델 파일 접근, Python 실행을 지원하는 AI 어시스턴트 환경에서 사용하세요.

### 1. AI에게 설치 요청하기

아래 문장을 복사해 보내세요.

```text
https://github.com/BensonZeng00/automated-3d-model-splitting 에서 automated-3d-model-splitting 2.1.0 Skill과 필요한 의존성을 설치해 주세요. 설치가 끝나면 포함된 고양이 머리 예제 cathead.3mf로 먼저 사용해 볼지 물어봐 주세요.
```

예제로 사용 흐름을 익히거나 자신의 모델로 바로 시작할 수 있습니다.

### 2. 모델을 전달하고 원하는 결과 말하기

페인팅된 3MF를 업로드하거나 파일 위치를 알려 준 뒤 이렇게 요청하세요.

```text
$automated-3d-model-splitting을 사용해 이 모델을 색상별로 출력하고 조립할 수 있는 파트로 나눠 주세요. 원래 배색을 유지하고 조립형 3MF를 제공한 뒤 검증 결과를 설명해 주세요.
```

중요한 부분이 있다면 “눈, 입, 혀를 유지하고 다른 파트에 가려지지 않게 해 주세요”처럼 덧붙이면 됩니다. 판단이 필요한 작은 영역은 AI가 이미지로 보여 주고 선택에 따라 진행합니다.

### 3. 결과를 열고 출력 준비하기

처리와 검증이 완료되면 **조립형 `.3mf` 파일**을 받습니다. 원래 배색과 조립 위치를 유지하면서 각 파트를 개별적으로 선택할 수 있습니다. 슬라이서에서 파일을 열어 세부 모습을 확인하고 파트별 출력 방법을 정하세요.

AI는 생성된 파트 수, 배색 유지 여부, 검사 통과 여부, 확인이 필요한 사항도 설명합니다. 처리가 완료되지 않았다면 어느 단계에서 멈췄고 어디까지 진행했는지 알려 줍니다.

## 출력 전에 알아둘 점

**조립 시 맞물림은 시험 출력으로 확인하세요.** 현재 버전은 조립 여유를 두기 위해 기본적으로 본체 외 파트 전체를 원래 크기의 99%로 축소합니다. 본체 크기는 유지합니다. 외형 치수와 이음새 간격도 달라지므로 모델, 재료, 출력 설정에 맞춰 확인해야 합니다.

**파일 검사만으로 실제 조립까지 확인할 수는 없습니다.** AI는 모델, 배색, 조립 상태를 검사하고 허용 오차 범위에서 통과한 항목도 설명합니다. 출력 전에 슬라이서에서 전체 모델, 파트 목록, 눈과 입 같은 세부 요소를 살펴보세요. 판단에 도움이 필요하면 스크린샷을 AI에게 전달할 수 있습니다.

복잡한 모델은 처리 진행 상황과 문제 기록을 남겨 달라고 요청하면 나중에 작업을 이어 가기 쉽습니다.
