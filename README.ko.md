# 자동 3D 모델 파트 분할

[简体中文（기본）](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

3D 프린팅은 좋아하지만 모델링은 어렵나요? 그래도 직접 파트를 분리할 수 있습니다.

색칠이 끝난 것처럼 보이는 모델도 실제로는 하나의 메시에 불과한 경우가 많습니다. 눈, 입, 의상, 장식 등을 따로 출력하려면 보통 모델링 프로그램에서 자르고, 면을 막고, 소켓을 만들고, 조립 간격을 반복 조정해야 합니다.

이 도구는 일반 사용자와 취미 제작자를 위한 AI 3D 모델 분할 Skill입니다. 컬러 또는 페인팅된 3MF를 전달하면 출력 가능한 색상 영역을 인식하고, 삽입부와 맞춤 소켓을 생성한 뒤, 슬라이싱 가능한 검증된 조립형 3MF를 출력합니다. 단색 모델은 아직 지원하지 않습니다.

Blender나 CAD를 배울 필요도, 복잡한 파라미터와 씨름할 필요도 없습니다.

## 주요 기능

- 표면 색상을 기준으로 독립 출력 파트 자동 인식
- 기하학 및 구조적 근거에 따른 본체 선택
- 각 파트의 안쪽 삽입 구조와 대응 소켓 생성
- 원래 색상과 AMS 필라멘트 슬롯 보존
- 모든 파트를 하나의 그룹 조립 모델로 출력
- 중첩 파트의 재귀 처리와 각 단계 검증
- 부모 파트 두께에 맞춘 삽입 깊이와 조립 간격 조정
- 토폴로지, 와인딩, 색상, 재료 슬롯, 조립 구조 및 보이는 디테일 최종 검사

## 설치

AI 어시스턴트에게 다음 문장을 보내세요.

```text
https://github.com/BensonZeng00/automated-3d-model-splitting 에서 automated-3d-model-splitting Skill을 설치하고, 필요한 의존성을 설치한 뒤 사전 검사를 완료해 주세요. 완료되면 cathead 예제로 테스트할지 물어보고, 동의하면 자동으로 파트를 분할해 결과를 알려 주세요.
```

설치와 사전 검사가 성공하면 어시스턴트가 `cathead` 예제 테스트 여부를 묻습니다. 동의하면 검증된 예제를 자동으로 가져와 파트를 인식하고, 조립형 3MF를 생성한 뒤 결과까지 검증합니다. 거절하면 예제를 다운로드하거나 읽지 않습니다.

## 사용법

페인팅된 3MF를 업로드한 뒤 다음과 같이 요청하세요.

```text
$automated-3d-model-splitting을 사용해 이 모델을 분할하고, 그룹 조립 모델과 최종 검증 결과를 출력해 주세요.
```

중요한 디테일을 직접 지정할 수도 있습니다.

```text
이 모델을 분할해 주세요. 입, 혀, 눈이 가려지지 않게 하고 검증 결과를 남겨 주세요.
```

## 결과물

본체, 눈, 입, 장식 등의 위치와 색상 관계를 유지하면서 각 파트를 따로 선택하고 출력할 수 있는 하나의 조립형 `.3mf` 파일을 받게 됩니다.

어시스턴트는 파트 수, 보존된 색상, 조립 구조, 검증 결과도 함께 보고합니다. 슬라이서 확인이 필요하면 최종 파일을 직접 열고 전체 모델, 펼친 조립 트리, 중요 디테일의 스크린샷을 제공해 주세요. Skill은 슬라이서를 대신 조작하지 않습니다.

## 적합한 모델

현재 버전은 삼각형 단위 표면 페인트 정보가 있는 3MF를 대상으로 합니다. 파일이 손상되었거나 구조가 모호하거나 구분할 수 없는 여러 인스턴스가 있으면 임의로 추측하지 않고 이유를 설명한 뒤 중단합니다.
