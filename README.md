# 自动化3d模型拆件

[简体中文（默认）](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

**把涂好颜色的一体模型，拆成可以分色打印、再组装的零件。**

下载了一只喜欢的小猫，想把眼睛、鼻子、耳朵分别打印，打开文件才发现：颜色分好了，零件却没有分开。自己动手拆，又得学建模、切割、做安装孔。

这个工具就是帮你跨过这一步的。把支持的涂色 3MF 交给 AI 助手，它会按颜色拆出零件、做好对应的安装位，交给你一个保留配色和装配关系的 3MF 文件，方便继续切片、分件打印和组装。

适合喜欢 3D 打印、想自己做多色作品，又不熟悉建模的玩家。想打印一只小猫，不必先给自己加一门建模课。

## 哪些时候能用上

| 你的困扰 | 它能帮上的忙 |
| --- | --- |
| 模型已经涂色，却没法把眼睛、嘴巴或装饰件单独选出来打印 | 把适合拆出的颜色区域变成独立零件，方便分别安排颜色和打印 |
| 想分开打印再组装，但不会做安装位 | 拆件时一并做好对应的插接结构，并预留装配空间 |
| 担心拆完后颜色乱了，或不知道零件该装在哪里 | 保留原有配色、AMS 耗材槽和装配位置，打开文件仍能看到完整模型 |
| 小花纹要不要单独打印，光看文字拿不准 | 对需要确认的小区域展示整模和放大图，由你选择是否保留为独立零件 |

## 我的模型能用吗

目前重点支持 **Bambu 涂色项目 3MF**，文件中需要保存工具可识别的涂色信息。只有 `.3mf` 后缀，或看起来有颜色，并不一定能用；可以先让 AI 助手检查文件。

单色模型自动分件暂不支持。特别薄、已经破损或零件关系复杂的模型，可能需要进一步修复或由你确认拆法。

## 怎么开始

这是一个供 AI 助手使用的 Skill（技能）。请在支持安装 Skill、读取模型文件和运行 Python 的 AI 助手环境中使用。

### 1. 让 AI 帮你安装

复制下面这段话发给 AI 助手：

```text
请从 https://github.com/BensonZeng00/automated-3d-model-splitting 安装 automated-3d-model-splitting 2.1.0 Skill 和所需依赖。装好后，问我是否用仓库自带的小猫头 cathead.3mf 试一次。
```

可以先用示例熟悉流程，也可以直接提供自己的模型。

安装时应复制仓库中完整的 `skills/automated-3d-model-splitting/` 目录，包含 `SKILL.md`、`scripts/`、`references/`、`tools/` 和 `requirements.txt`。入口脚本位于该技能目录下的 `scripts/split_painted_3mf.py`，不在当前项目根目录；只复制 `SKILL.md` 无法运行。

### 2. 提供模型，说出你的要求

上传涂色 3MF，或告诉 AI 文件的位置，然后说：

```text
使用 $automated-3d-model-splitting 帮我把这个模型拆成可以分色打印、再组装的零件。保留原来的配色，完成后给我装配版 3MF，并说明检查结果。
```

有特别在意的细节，直接补充就行，例如：“眼睛、嘴巴和舌头要保留，不能被其他零件挡住。”需要你判断的小区域，AI 会展示图片，再根据你的选择继续。

### 3. 打开结果，准备打印

完成并通过检查后，你会拿到一个**装配版 `.3mf` 文件**：各零件可以单独选择，仍保留原来的配色和装配位置。用切片软件打开后，就可以检查细节、安排各零件的打印方式。

AI 还会说明拆出了多少个零件、配色是否保留、检查是否通过，以及哪些地方需要你留意。如果处理没有完成，也会说明卡在哪里和已经完成的进度。

## 打印前还需要知道什么

**装配松紧需要试打确认。** 当前版本默认将主体以外的零件整体缩至原尺寸的 99%，主体保持原尺寸，为安装留出余量。缩小也会影响零件外观尺寸和接缝；最终是否合适，还要结合模型、材料和打印设置判断。

**文件检查不等于实物试装。** AI 会检查模型、配色和装配情况，并说明按容差规则通过的项目。打印前，请在切片软件里看看整体模型、零件列表和眼睛、嘴巴等重点细节；需要协助判断时，把截图发给 AI 即可。

遇到复杂模型时，可以让 AI 保留处理进度和问题记录，便于后续继续处理。
