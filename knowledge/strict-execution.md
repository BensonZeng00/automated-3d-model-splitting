# 准入、失败退出与低输出日志

## 已落实的约束

- 子模型选择必须早于涂色解码。标识采用包内路径和 mesh object ID，不能只凭面数或同名文件推断目标。工件续跑绑定保存的源指纹及对象身份。
- 原始与展开后面数仅作统计，不再作为准入门槛。零件复杂度以区域及边界统计和实际闭环、接口构造、自接触检查评估；在昂贵操作之前检查预算，续跑入口也必须重查。
- 计数上限已废除；剩余资源预算不代表几何能力，尚未形成覆盖各种模型的成功率标定。通过部分检查不等于证明可打印；未检查的条件要写为 pending。
- 允许当前代码已实现且符合约束的修复和恢复，修复后重新验证；没有适用流程或修复失败则退出。禁止拆件执行中临时修改代码、Skill、阈值或绕过检查。
- stdout 给状态、计数和路径；JSONL 保留完整证据。INFO/ERROR 只保留有界消息和标量信息，大型诊断进入 DEBUG。先读摘要，再筛选错误和相关阶段，不默认读取整个日志。
- 测试应验证控制流：过预算时后续构造不被调用，深度候选有限回退但只查询一次射线，冻结输入保持不变，错误信息完整落盘且终端输出有界。

## 取舍

内置恢复和临时改代码是不同权限。本次开发已恢复被误删的既有深度/宽度候选、输出闭合和朝向修复；开发任务可以单独调整实现，不能在普通拆件执行中为个案修改。

紧凑审核图减少默认视觉输入，但不能替代看不清的细节证据。每个区域仍须有明确语义和置信度；仅对不明确区域展开原图。

## 修正：计数不代表结构不支持

黄金回归发现已批准模型也有大量原始涂色区域，因此废除区域、边界环和边界点数量准入阈值。计数只报告工作量；不因边界分叉计数直接退出；实际闭环提取失败、超出有界规则的自接触和构造规则失败提供结构证据。XML 大小与涂色编码长度仍为独立资源预算，返回 budget_exceeded。黄金测试读取统一 JSON 摘要，不能修改黄金模型或预期结果以掩盖回归。

## 修正：执行权限与算法恢复分开

“不得运行中改代码或 Skill”限制的是代理的临时开发操作，不是禁止算法已经实现的有界恢复。保持原算法候选上限、最小深度、接触预算和修复后验证；异常诊断完整保存到日志，禁止以修改黄金预期来证明恢复有效。

接触审计的范围必须绑定实际装配接口；不能遍历所有源候选边界并提前阻断。源缺陷与输出接口缺陷不同。黄金子测试失败可能直到摘要才显示，不能凭进度点号宣布某模型全部通过。

诊断黄金失败前先查仓库已有测试记录，再区分新回归与历史已知偏差；不能只因本次运行失败就把原因归于最近修改。

## 安装前风险告知

安装前必须同时说明复杂模型可能失败，以及失败仍可能消耗较多 token 和额度；仅说明 token 消耗不足以表达失败风险。不提供未经测量的成功率或失败率数字。收集 Coding Plan 情况及明确知情同意后再安装，四种语言的安装入口与 Skill 保持一致。
