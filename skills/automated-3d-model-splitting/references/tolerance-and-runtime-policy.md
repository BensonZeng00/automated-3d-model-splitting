# Source 保持与运行策略

## 审核阈值

识别先自动过滤总表面积 `<1 mm²` 的连通涂色区域；这些区域不成为零件候选，源网格与逐面涂色仍保持不变。对剩余区域，`<=100` 面是 noise 候选，`101–999` 面是小区域候选，长细条不受面数限制。审核候选需用户分类为 `noise`、`part` 或 `uncertain`；分类不改变 source，也不跳过正常拆件。

## 非阻断 source 诊断

1%、1–2 mm、开边、翻转面、非流形、微孔和断开壳体只作诊断，不触发合并、删除、补面、翻面、重试或阻断。面积小于 `1 mm²` 的涂色区域按识别规则排除为噪声。接口碰到异常时只重规划接口局部。

## 性能

不得为无关 source 缺陷运行全模型 containment、winding、封孔或微网格修复。缓存只复用来源、参数和实现指纹均匹配且已验证的拆件阶段。
